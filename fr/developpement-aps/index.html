Développement APS sur mesure

J'accompagne les entreprises dans le développement d'applications Web et Cloud basées sur Autodesk Platform Services (APS, anciennement Forge). Mon objectif : vous permettre d'exploiter vos données CAO au-delà du poste de travail, en les intégrant dans vos applications Web, vos portails clients ou vos processus métier.

APS est un ensemble d'API cloud proposées par Autodesk qui ouvrent de nouvelles possibilités : visualisation 3D dans le navigateur, traitement automatisé de fichiers CAO côté serveur, gestion de données de construction...

Les services

Visionneuse (Viewer)

La visionneuse Autodesk permet d'afficher des modèles 3D et des plans 2D directement dans le navigateur, sans installation côté client. Elle est optimisée pour les modèles volumineux et propose de nombreuses fonctionnalités : navigation 3D, sélection d'objets avec affichage des propriétés, coupes, mesures, vue éclatée...

C'est une solution idéale pour les catalogues de pièces détachées, les portails clients ou les outils de revue de projet.

API Automation (Design Automation)

L'API Automation permet d'exécuter AutoCAD, Inventor, Revit ou 3ds Max sur des serveurs cloud pour traiter des fichiers automatiquement. On installe un complément .NET ou un script dans APS, puis on lui envoie des fichiers à traiter avec des paramètres personnalisés.

Cas d'usage typiques : personnalisation de plans à la volée, génération de variantes de modèles 3D, conversion de formats, extraction de données en masse...

Model Derivative API

Cette API permet de convertir des fichiers CAO (DWG, RVT, IPT, IAM...) en formats exploitables sur le Web (SVF/SVF2). C'est le passage obligé pour afficher un fichier dans la visionneuse. Elle permet aussi d'extraire les métadonnées et la hiérarchie du modèle.

Data Management API

L'API de gestion des données permet d'accéder aux fichiers stockés dans les hubs Autodesk (BIM 360, Autodesk Construction Cloud, Fusion Team). Elle gère le versioning, les permissions et la navigation dans l'arborescence des projets.

Webhooks

Les webhooks APS permettent de réagir à des événements : modification d'un fichier, changement de statut, nouvelle version... C'est le mécanisme idéal pour déclencher des traitements automatiques dans votre flux de travail.

Ce que je peux développer

Voici un aperçu de projets réalisés :

  • Intégration de la visionneuse Autodesk — Mise en place d'un visualiseur 3D/2D dans un portail Web pour un catalogue de pièces détachées
  • Traitement automatisé de fichiers — Personnalisation de plans AutoCAD côté serveur avec injection de données client
  • Conversion et extraction de données — Transformation de fichiers CAO et extraction de métadonnées pour alimentation d'autres systèmes
  • Intégration avec des plateformes tierces — Connexion entre APS et des outils métier (ERP, CRM, portails Web)
