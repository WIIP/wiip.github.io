Développement Inventor sur mesure

Depuis 2008, j'accompagne les bureaux d'études et les industriels dans le développement de compléments Inventor sur mesure. Mon objectif : automatiser vos tâches de conception répétitives, fiabiliser vos processus, améliorer le confort de vos utilisateurs et réduire le risque d'erreurs.

Inventor est un outil puissant pour la conception mécanique 3D, mais sa richesse fonctionnelle peut être décuplée grâce à des développements personnalisés qui s'intègrent directement dans votre flux de travail.

Les technologies

C# / .NET (API Inventor)

C'est la technologie principale pour développer des plugins Inventor. L'API .NET d'Inventor est très complète : accès au modèle 3D, aux assemblages, aux dessins, aux paramètres, aux contraintes... Elle permet de créer des commandes personnalisées, des interfaces utilisateur riches et des automatismes avancés.

C'est mon langage principal. Je l'utilise pour la majorité de mes projets Inventor.

iLogic

iLogic est le moteur de règles intégré à Inventor. Il permet d'écrire des scripts en VB.NET directement dans le document Inventor pour automatiser des comportements : configuration de pièces paramétriques, gestion de variantes, mise à jour automatique de propriétés...

iLogic est particulièrement adapté aux cas où l'automatisme doit voyager avec le document. Je peux développer des règles iLogic complexes ou les combiner avec des plugins .NET pour des solutions hybrides.

VBA

Inventor intègre un éditeur VBA qui permet de créer des macros rapidement. Comme pour AutoCAD, VBA a l'avantage d'être un langage familier pour les utilisateurs de MS Office ou SolidWorks. Il convient pour des automatismes simples ou pour prototyper une solution avant un développement .NET plus abouti.

Apprentice Server

Apprentice est une bibliothèque fournie par Autodesk qui permet de lire et modifier des fichiers Inventor sans Inventor. C'est l'équivalent de RealDWG pour le monde Inventor. Idéal pour les applications serveur, les traitements par lots ou les outils de vérification.

Ce que je peux automatiser

Voici un aperçu de projets réalisés pour mes clients :

  • Tracé d'esquisses complexes — Génération automatique de profils paramétriques à partir de spécifications techniques
  • Connexion avec un ERP — Intégration bidirectionnelle avec des systèmes comme Clipper, Sage X3 : synchronisation des nomenclatures, des propriétés et des statuts
  • Collecte de cotes et tolérances — Extraction automatique des GD&T depuis les dessins pour générer des procès-verbaux de contrôle qualité
  • Génération de fiches de débits — Création automatique de documents de découpe pour profilés de menuiseries
