Prévisualiser des fichiers DWG et DXF avec QuickLook

vendredi 13 mars 2026
CAOAutoCADDWGDXF

Quand on travaille avec des fichiers DWG ou DXF au quotidien, ouvrir AutoCAD juste pour vérifier le contenu d'un fichier est une perte de temps. QuickLook résout ce problème en apportant à Windows la fonctionnalité Quick Look de macOS : sélectionnez un fichier, appuyez sur Espace, et une prévisualisation apparaît instantanément.

Combiné au plugin CADImport, QuickLook devient capable de prévisualiser les fichiers .dwg et .dxf.

Installer QuickLook

QuickLook peut être installé de deux manières :

Via le Microsoft Store (recommandé)

C'est la méthode la plus simple. L'application se met à jour automatiquement et s'exécute dans un environnement sécurisé (sandbox).

Recherchez QuickLook dans le Microsoft Store ou cliquez ici.

Via le programme d'installation

Téléchargez le programme d'installation depuis la page des releases GitHub. Cette méthode offre toutes les fonctionnalités, y compris le support des boîtes de dialogue Ouvrir/Enregistrer.

Une fois installé, QuickLook se lance automatiquement au démarrage de Windows et s'installe dans la zone de notification (barre des tâches).

Installer le plugin CADImport

  1. Rendez-vous sur la page des releases du plugin CADImport.
  2. Téléchargez le fichier .qlplugin.
  3. Avec QuickLook en cours d'exécution, sélectionnez le fichier .qlplugin téléchargé et appuyez sur Espace.
  4. Cliquez sur Installer dans la fenêtre qui s'affiche.
  5. Redémarrez QuickLook.

Utilisation

Le fonctionnement est très simple :

  1. Sélectionnez un fichier .dwg ou .dxf dans l'explorateur Windows.
  2. Appuyez sur la touche Espace.
  3. La prévisualisation du dessin s'affiche immédiatement.

Navigation dans la prévisualisation

  • Molette de la souris : zoom avant / arrière
  • Double-clic gauche : réinitialiser le zoom
  • Clic droit maintenu + glisser : déplacer la vue (panoramique)
  • Échap ou Espace : fermer la prévisualisation

Conclusion

QuickLook avec le plugin CADImport est un outil simple mais redoutablement efficace pour quiconque travaille régulièrement avec des fichiers AutoCAD. Plus besoin d'ouvrir un logiciel de CAO pour identifier rapidement le contenu d'un fichier — un simple appui sur Espace suffit.
