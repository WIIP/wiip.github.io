Miniatures Inventor absentes dans l'Explorateur Windows : diagnostic et solution

mardi 29 septembre 2026
InventorWindowsCAO

Vous ouvrez un dossier de pièces et d'assemblages Inventor dans l'Explorateur Windows, en affichage Grandes icônes : pas une seule miniature, uniquement l'icône générique d'Inventor.

Les fichiers concernés sont ceux d'Inventor : .ipt (pièces), .iam (assemblages), .ipn (présentations), .idw et .dwg (mises en plan). Voici les causes possibles, de la plus simple à la plus cachée, avec pour chacune la façon de la reconnaître et de la corriger.

Le résultat attendu, une fois le problème réglé :

Comment l'Explorateur affiche une miniature Inventor

L'Explorateur ne sait pas lire un fichier Inventor. Pour chaque extension, il cherche dans le registre un gestionnaire de miniatures : une DLL installée avec Inventor, qui extrait l'aperçu enregistré dans le fichier. Il le cherche sous l'extension elle-même (.ipt), sous le type de fichier associé (Inventor.PartDocument, par exemple) et sous SystemFileAssociations.

Pour qu'une miniature apparaisse, il faut donc que les miniatures soient activées, que le fichier contienne un aperçu, qu'un gestionnaire soit déclaré, que sa DLL existe et que Windows accepte de la charger. Chaque maillon peut casser.

1. Les miniatures sont désactivées dans l'Explorateur

Diagnostic : dans l'Explorateur, menu … → Options → onglet Affichage. Si Toujours afficher des icônes, jamais des miniatures est cochée, aucun fichier n'a de miniature, pas seulement ceux d'Inventor.

Correction : décochez l'option, puis OK.

Si la case est grisée, ou se recoche toute seule, c'est une stratégie de groupe qui l'impose : voyez avec l'administrateur de votre réseau.

2. Le cache des miniatures est périmé

Windows garde les miniatures dans un cache. S'il a mémorisé un fichier comme « sans aperçu », il ne le réinterroge pas, même une fois le problème réglé.

Diagnostic : difficile à établir seul. C'est pourquoi on vide le cache par principe, et après chaque correction décrite plus bas.

Correction : lancez Nettoyage de disque (cleanmgr), cochez Miniatures, puis OK. Fermez ensuite votre session Windows et rouvrez-la : l'Explorateur ne recharge pas toujours un gestionnaire pendant qu'il tourne.

3. Le fichier ne contient pas d'aperçu

Le gestionnaire ne calcule rien : il affiche l'image qu'Inventor a enregistrée dans le fichier. Un fichier créé par un traitement automatique, par exemple, peut ne pas en avoir.

Diagnostic : ouvrez une pièce dans Inventor, modifiez-la, enregistrez-la. Si ce fichier-là affiche sa miniature et pas les autres, ce sont les autres qui n'ont pas d'aperçu.

Correction : ouvrez et réenregistrez ces fichiers dans Inventor.

4. Le fichier est sur un lecteur réseau ou dans OneDrive

Une stratégie d'entreprise peut désactiver les miniatures sur les dossiers réseau, et un fichier OneDrive ou SharePoint « disponible en ligne uniquement » n'en affiche pas.

Diagnostic : copiez un fichier sur le bureau. S'il y affiche sa miniature, l'emplacement est en cause.

Correction : pour OneDrive, clic droit sur le dossier → Toujours conserver sur cet appareil. Pour un lecteur réseau, voyez avec l'administrateur.

5. Aucun gestionnaire n'est déclaré pour l'extension

Une autre application peut s'être approprié l'extension, ou une ancienne version d'Inventor a laissé, à sa désinstallation, des clés qui ne mènent plus nulle part. C'est fréquent pour .dwg, que se disputent Inventor, AutoCAD et DWG TrueView.

Diagnostic : ouvrez l'Éditeur du Registre (regedit) et cherchez la clé suivante, en remplaçant .ipt par l'extension qui pose problème :

HKEY_CLASSES_ROOT\.ipt\ShellEx\{e357fccd-a995-4576-b01f-234630154e96}

Ce long identifiant désigne les gestionnaires de miniatures. Si la clé n'existe pas, regardez la valeur (par défaut) de HKEY_CLASSES_ROOT\.ipt : elle donne le type de fichier associé (par exemple Inventor.PartDocument). Cherchez alors la même sous-clé ShellEx\{e357fccd-a995-4576-b01f-234630154e96} sous ce type de fichier. Si elle n'existe à aucun des deux endroits, aucun gestionnaire n'est déclaré.

Quand elle existe, notez sa valeur (par défaut) : c'est l'identifiant (CLSID) du gestionnaire, une chaîne de la forme {XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX}. Il servira aux deux points suivants.

Correction : clic droit sur un fichier → Ouvrir avec → Choisir une autre application → votre version d'Inventor → Toujours. Si la clé reste absente, lancez une réparation d'Inventor depuis Paramètres → Applications → Applications installées.

6. La DLL du gestionnaire n'existe plus

Diagnostic : dans l'Éditeur du Registre, ouvrez la clé suivante, en remplaçant {CLSID} par l'identifiant noté au point 5 :

HKEY_CLASSES_ROOT\CLSID\{CLSID}\InprocServer32

Sa valeur (par défaut) donne le chemin de la DLL. Vérifiez dans l'Explorateur que ce fichier existe bien. Un chemin qui pointe vers une version d'Inventor désinstallée, ou vers un disque qui n'existe plus, trahit le problème.

Correction : réparez la version d'Inventor installée, comme au point 5 : elle réenregistre son gestionnaire.

7. Le gestionnaire est bloqué par Windows

C'est la cause la plus sournoise : tout est installé et déclaré correctement, mais Windows a ordre de ne jamais charger ce gestionnaire. Aucun message ne le signale. Ce blocage est souvent posé pour faire taire une extension qui faisait planter ou ralentir l'Explorateur, puis oublié ; un logiciel de sécurité ou une stratégie de groupe peut aussi l'avoir posé.

Diagnostic : Windows tient cette liste noire à deux endroits, l'un pour tout le poste, l'autre pour l'utilisateur :

HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Shell Extensions\Blocked
HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Shell Extensions\Blocked

Ouvrez ces deux clés dans l'Éditeur du Registre. Si l'une d'elles contient une valeur portant le nom du CLSID noté au point 5, le gestionnaire est bloqué.

Correction : retirez cette valeur de la liste. Trois façons de faire, au choix.

Avec ShellExView, sans toucher au registre. Windows n'offre aucune interface pour gérer cette liste, mais l'outil gratuit ShellExView, de NirSoft, le fait : sa commande Disable ajoute une extension à la liste, et Enable l'en retire.

  1. Téléchargez ShellExView en version 64 bits sur le site de NirSoft et lancez-le en tant qu'administrateur.
  2. Cherchez les lignes dont la colonne Product Name indique Autodesk Inventor et la colonne Type Thumbnail : ce sont les gestionnaires de miniatures d'Inventor. La colonne Disabled indique s'ils sont bloqués (Yes) ou non (No).
  3. Sélectionnez les lignes bloquées, faites un clic droit, puis Enable Selected Items.

Avec l'Éditeur du Registre. Dans la clé Blocked concernée, faites d'abord une sauvegarde (clic droit sur la clé → Exporter), puis supprimez la valeur (clic droit → Supprimer). Sous HKEY_LOCAL_MACHINE, il faut des droits d'administrateur.

En ligne de commande, pratique pour corriger plusieurs postes. Dans une invite de commandes lancée en administrateur, en remplaçant {CLSID} par l'identifiant :

reg export "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Shell Extensions\Blocked" "%USERPROFILE%\Desktop\Blocked-sauvegarde.reg"
reg delete "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Shell Extensions\Blocked" /v {CLSID} /f

Si la valeur est sous HKEY_CURRENT_USER, remplacez HKLM par HKCU et lancez la commande dans la session de l'utilisateur, sans élévation : lancée par un administrateur avec son propre compte, elle modifierait le registre de l'administrateur.

Si la valeur réapparaît après un redémarrage ou un gpupdate, c'est une stratégie de groupe ou un antivirus qui l'impose : il faut voir avec l'administrateur du domaine. Et si le blocage avait été posé volontairement, vérifiez ensuite que la navigation dans vos dossiers Inventor les plus chargés reste fluide.

En résumé

Cause Diagnostic Correction
Miniatures désactivées Aucun fichier n'a de miniature Décocher « Toujours afficher des icônes »
Cache périmé — Nettoyage de disque → Miniatures
Fichier sans aperçu Un fichier réenregistré a sa miniature Réenregistrer dans Inventor
Réseau ou OneDrive Une copie sur le bureau a sa miniature Conserver sur l'appareil, ou voir l'administrateur
Aucun gestionnaire Clé ShellEx\{e357fccd-…} absente Réassocier l'extension, réparer Inventor
DLL absente Chemin InprocServer32 introuvable Réparer Inventor
Gestionnaire bloqué CLSID dans Shell Extensions\Blocked ShellExView, regedit ou reg delete

Après chaque correction, videz le cache des miniatures et rouvrez votre session Windows.
