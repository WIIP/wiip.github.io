« Ouvrir avec » : distinguer les versions d'AutoCAD sous Windows

dimanche 25 octobre 2026
AutoCADCAOWindows

Vous avez plusieurs versions d'AutoCAD installées : celle de l'an dernier pour un client qui n'a pas encore migré, la nouvelle pour le reste. Vous faites un clic droit sur un fichier DWG, Ouvrir avec… et voici ce que propose Windows :

Quatre AutoCAD installés, quatre entrées « AutoCAD Application ». Laquelle est AutoCAD 2026 ?

Les quatre entrées ont le même nom et la même icône. Impossible de savoir quelle version va se lancer sans essayer. Dans cet article, nous allons voir pourquoi Windows affiche ce nom, puis comment obtenir ceci :

Le même menu, une fois chaque entrée nommée d'après sa version.

La correction ne demande pas de droits d'administrateur : elle ne touche que votre profil utilisateur, et elle se défait en une commande.

Le double-clic sur un DWG, lui, passe par un petit programme d'Autodesk, AutoCAD Launcher, qui ouvre le dernier AutoCAD utilisé. Nous l'expliquons dans C'est quoi AutoCAD Launcher ?. Le présent article s'occupe du menu Ouvrir avec, qui sert justement à choisir une autre version.

D'où vient « AutoCAD Application » ?

Chaque version d'AutoCAD déclare dans le registre de Windows un ProgID, un identifiant de programme, par exemple acad.9101.40C. C'est lui qui dit à Windows quel exécutable lancer pour ouvrir un DWG (C:\Program Files\Autodesk\AutoCAD 2026\acad.exe, par exemple).

Pour savoir quel nom afficher dans le menu, l'Explorateur cherche d'abord une valeur FriendlyAppName sur ce ProgID. AutoCAD n'en déclare pas. L'Explorateur se rabat alors sur la description de fichier de l'exécutable, celle que vous voyez dans l'onglet Détails des propriétés de acad.exe. Or, de la version 2024 à la version 2027 au moins, cette description est la même pour tous : « AutoCAD Application ».

Windows garde ensuite ce nom en cache, dans la clé :

HKEY_CURRENT_USER\Software\Classes\Local Settings\Software\Microsoft\Windows\Shell\MuiCache

Il est inutile de modifier ce cache : une valeur FriendlyAppName posée sur le ProgID passe avant lui.

Le remède : une valeur FriendlyAppName

Il suffit donc d'ajouter, pour chaque ProgID d'AutoCAD, une valeur texte FriendlyAppName dans la clé :

HKEY_CURRENT_USER\Software\Classes\<ProgID>\shell\open

avec pour contenu le nom à afficher : AutoCAD 2026.

Rien d'autre ne change : la commande d'ouverture, l'association par défaut des DWG et le double-clic restent tels quels. Le seul effet est le nom affiché dans Ouvrir avec.

Vous pouvez le faire à la main dans l'Éditeur du Registre, ou avec le script que nous proposons plus bas, qui trouve les bons ProgID tout seul.

À la main, avec l'Éditeur du Registre

Cette méthode convient si vous n'avez que deux ou trois versions à renommer.

  1. Appuyez sur Windows + R, tapez regedit et validez. Si Windows demande une confirmation, acceptez : vous resterez dans votre propre profil.
  2. Dans la barre d'adresse en haut de l'Éditeur du Registre, collez HKEY_CURRENT_USER\Software\Classes\.dwg\OpenWithProgids et appuyez sur Entrée.
  3. La partie droite liste des noms comme acad.8101.40C ou acad.9101.40C : ce sont les ProgID déclarés pour les DWG. Notez ceux qui commencent par acad..
  4. Pour chacun, collez HKEY_CURRENT_USER\Software\Classes\acad.9101.40C\shell\open\command dans la barre d'adresse (en remplaçant acad.9101.40C par le ProgID noté). La valeur (par défaut) donne le chemin de l'exécutable : le dossier AutoCAD 2026 vous dit la version.
  5. Remontez d'un cran, sur la clé shell\open. Faites un clic droit dans la partie droite, Nouveau > Valeur chaîne, nommez-la FriendlyAppName, puis double-cliquez dessus et saisissez AutoCAD 2026.
  6. Fermez le menu Ouvrir avec s'il était ouvert, puis rouvrez-le : le nouveau nom apparaît.

Si la clé shell\open n'existe pas sous HKEY_CURRENT_USER\Software\Classes\<ProgID>, ce ProgID a été déclaré pour toute la machine : le renommer demanderait les droits d'administrateur. Laissez-le de côté.

Pour revenir en arrière, supprimez simplement la valeur FriendlyAppName.

Avec le script PowerShell

Le script RenameDwgOpenWith.ps1 fait la même chose pour toutes les versions installées d'un coup :

  • il lit la liste des ProgID associés aux DWG ;
  • il garde ceux dont l'exécutable est un acad.exe installé dans un dossier AutoCAD AAAA ;
  • il en tire le nom AutoCAD AAAA et l'écrit en FriendlyAppName.

Par défaut, il ne modifie rien : il affiche ce qu'il ferait. Il n'écrit qu'avec le commutateur -Apply, après avoir sauvegardé chaque clé qu'il va toucher. Le commutateur -Undo retire les noms qu'il a posés.

Avertissement. Ce script est fourni gratuitement, tel quel, sans aucune garantie. Nous l'avons testé sur un poste Windows 11 où étaient installés AutoCAD 2024, 2025, 2026 et 2027, mais nous ne pouvons pas garantir son comportement sur votre configuration. Il modifie le registre de Windows, uniquement dans votre profil utilisateur (HKEY_CURRENT_USER). Lancez toujours la simulation d'abord, lisez ce qu'elle annonce, et gardez les sauvegardes qu'il crée. Vous l'utilisez sous votre propre responsabilité.

Étape 1 : télécharger le script

  1. Téléchargez RenameDwgOpenWith.ps1. Si le navigateur affiche le texte au lieu de télécharger le fichier, faites un clic droit sur le lien et choisissez Enregistrer le lien sous.
  2. Créez un dossier dédié, par exemple Documents\Scripts, et placez-y le fichier. Les sauvegardes du registre seront créées à côté, dans un sous-dossier Sauvegardes.

C'est un simple fichier texte : vous pouvez l'ouvrir dans le Bloc-notes pour le lire avant de le lancer. Nous vous y encourageons.

Étape 2 : ouvrir un terminal dans ce dossier

  1. Ouvrez le dossier Documents\Scripts dans l'Explorateur.
  2. Faites un clic droit dans une zone vide du dossier et choisissez Ouvrir dans le Terminal. Une fenêtre s'ouvre, dont l'invite se termine par Scripts>.

N'ouvrez pas le terminal en tant qu'administrateur. Le script écrit dans votre profil : lancé en administrateur, il écrirait dans le profil du compte administrateur, et vous ne verriez aucun changement.

Étape 3 : simuler

Copiez cette commande, collez-la dans le terminal (clic droit ou Ctrl+V) et appuyez sur Entrée :

powershell -NoProfile -ExecutionPolicy Bypass -File .\RenameDwgOpenWith.ps1

Par défaut, Windows refuse d'exécuter les scripts PowerShell téléchargés. -ExecutionPolicy Bypass lève ce blocage pour cette seule commande, sans changer le réglage de votre poste.

Le script affiche trois choses :

  • Avant : les entrées actuelles du menu Ouvrir avec, chacune suivie du programme qu'elle lance. Vous y verrez les lignes AutoCAD Application, avec leur chemin.
  • ProgID à renommer : un tableau qui donne, pour chaque ProgID, son nom actuel (vide), le nom qu'il recevra (AutoCAD 2026) et l'exécutable correspondant. Vérifiez que chaque nom correspond bien au dossier de l'exécutable.
  • La ligne Simulation : rien n'a été modifié.

Si le tableau est vide, il n'y a rien à renommer : soit c'est déjà fait, soit vos AutoCAD sont déclarés pour toute la machine (le script l'indique alors par un avertissement jaune).

Étape 4 : appliquer

Si le tableau vous convient, relancez la même commande avec -Apply :

powershell -NoProfile -ExecutionPolicy Bypass -File .\RenameDwgOpenWith.ps1 -Apply

Le script :

  1. exporte chaque clé qu'il va modifier dans un fichier .reg, dans le sous-dossier Sauvegardes (une ligne Sauvegarde : par fichier). Si une sauvegarde échoue, il s'arrête sans rien écrire ;
  2. écrit les noms ;
  3. prévient l'Explorateur que les associations ont changé ;
  4. affiche à nouveau le menu, dans la partie Après : vous devez y lire AutoCAD 2024, AutoCAD 2025…

Fermez le menu Ouvrir avec s'il était ouvert et rouvrez-le. Il n'est pas nécessaire de redémarrer l'Explorateur ni la session.

Si DWG TrueView est aussi installé, ajoutez -IncludeTrueView (en simulation, puis avec -Apply) pour qu'il s'affiche « DWG TrueView 2024 » au lieu de « DWG TrueView Application ».

Revenir en arrière

Depuis le même dossier :

powershell -NoProfile -ExecutionPolicy Bypass -File .\RenameDwgOpenWith.ps1 -Undo

Le script ne retire que les noms qu'il a lui-même posés : un FriendlyAppName que vous auriez saisi à la main, différent du sien, reste en place. Ajoutez -IncludeTrueView si vous l'aviez utilisé.

Les fichiers .reg du dossier Sauvegardes sont un second filet : un double-clic sur l'un d'eux remet la clé correspondante dans l'état où elle était avant -Apply.

Après une mise à jour d'AutoCAD

Une réparation, une mise à jour ou l'installation d'une nouvelle version peut réécrire les ProgID. Si des « AutoCAD Application » réapparaissent, relancez simplement le script avec -Apply : il ne réécrit que les noms manquants.

En résumé
Symptôme Plusieurs « AutoCAD Application » identiques dans Ouvrir avec
Cause Le ProgID d'AutoCAD ne fournit pas de nom ; l'Explorateur reprend la description de acad.exe, la même pour toutes les versions
Correction Une valeur texte FriendlyAppName sous HKEY_CURRENT_USER\Software\Classes\<ProgID>\shell\open
Droits nécessaires Aucun : profil utilisateur seulement
Retour arrière Supprimer la valeur, ou RenameDwgOpenWith.ps1 -Undo
