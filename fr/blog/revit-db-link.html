Revit DB Link : exporter les données d'un modèle vers une base de données

mercredi 18 mars 2026
RevitCAO

Revit DB Link est une extension développée par Autodesk qui permet d'exporter les données d'un modèle Revit vers une base de données externe (Microsoft Access, SQL Server, ODBC), puis de les réimporter après modification. C'est un outil précieux pour tous ceux qui ont besoin de manipuler en masse les paramètres de leurs éléments Revit sans passer par l'interface graphique.

À quoi ça sert ?

Revit DB Link exporte les propriétés des éléments du modèle (murs, portes, fenêtres, pièces, etc.) sous forme de tables dans une base de données. Chaque catégorie d'éléments correspond à une table, et chaque paramètre à une colonne.

Concrètement, cela permet de :

  • Consulter l'ensemble des données du modèle dans un format tabulaire, plus facile à analyser qu'en naviguant élément par élément dans Revit.
  • Modifier en masse des paramètres (noms de pièces, numéros de portes, valeurs personnalisées...) directement dans la base de données, puis réimporter les modifications dans le modèle.
  • Vérifier la cohérence des données en utilisant des requêtes SQL ou des filtres dans Access.
  • Créer des rapports ou des tableaux croisés dynamiques à partir des données exportées.

Installation

Revit DB Link n'est pas installé par défaut avec Revit. C'est une extension à part qu'il faut télécharger et installer séparément.

Pour l'obtenir :

  1. Rendez-vous sur manage.autodesk.com.
  2. Dans la section Produits et services, recherchez Revit. Cliquez sur Afficher les détails.
  3. Choisissez ensuite l'onglet correspondant à votre version de Revit, puis l'onglet Extensions.
  4. Téléchargez le programme d'installation DB Link for Revit 202x.
  5. Lancez l'installation.

Une fois installé, vous trouverez la commande Revit DB Link dans l'onglet Compléments du ruban Revit.

Utilisation

L'utilisation est simple :

  1. Ouvrez votre modèle Revit.
  2. Allez dans l'onglet Compléments et cliquez sur Revit DB Link.
  3. Choisissez le type de connexion (Access 2000 - 2003, Access 2007 - 2016 ou ODBC).
  4. Lancez l'export.

Pour réimporter les données modifiées, revenez sur Revit DB Link et choisissez Modifier et importer.

Le problème avec Microsoft Office 32 bits

Si vous utilisez Microsoft Office en version 32 bits (ce qui est encore fréquent en entreprise, même sur des machines 64 bits), vous risquez de rencontrer un problème lors de l'export vers Microsoft Access : l'option Sélectionner une nouvelle connexion pour créer un lien vers une base Access est tout simplement absente de la boîte de dialogue.

La cause est simple : Revit est une application 64 bits. Pour communiquer avec une base de données Access, il a besoin des pilotes ODBC en version 64 bits. Or, quand Office est installé en 32 bits, seuls les pilotes 32 bits sont présents sur la machine. Un processus 64 bits ne pouvant pas charger un pilote 32 bits, Revit DB Link ne propose pas l'option Access.

Solution

Pour vérifier si les pilotes 64 bits sont installés :

  1. Tapez Sources de données ODBC (64 bits) dans la barre de recherche Windows.
  2. Allez dans l'onglet Pilotes.
  3. Vérifiez que Microsoft Access Driver (*.mdb, *.accdb) est présent.

Si le pilote est absent, il faut installer Microsoft Access 2013 Runtime en version 64 bits. Une fois le programme téléchargé, lancez l'installation en double-cliquant sur AccessRuntime_x64_en-us.exe, puis relancez Revit.

Attention : Revit prend en charge Microsoft Access 2013 Runtime et les versions antérieures. L'installation de Microsoft Access 2016 Runtime n'est pas recommandée par Autodesk.

Pour plus de détails, consultez l'article de support Autodesk.
