Claude Code intègre un nouvel outil PowerShell

vendredi 3 avril 2026· mis à jour le jeudi 21 mai 2026
PowerShellClaude CodeIAProgrammation

Dans les dernières versions de Claude Code, il y a un nouvel outil en preview qui permet d'exécuter des commandes PowerShell directement au lieu de passer par Bash. Pour l'activer, il faut passer la variable d'environnement CLAUDE_CODE_USE_POWERSHELL_TOOL à 1.

Donc par exemple, à partir d'une invite de commande PowerShell, il faut lancer Claude Code avec la ligne de commande suivante :

$env:CLAUDE_CODE_USE_POWERSHELL_TOOL = "1"; claude

Le problème, c'est que Claude Code ne semble pas intéressé par PowerShell, il préfère Bash... Il faut lui dire explicitement d'utiliser PowerShell...

J'ai simplement ajouté les instructions suivantes dans mon fichier CLAUDE.md global :

## PowerShell

* Si tu as un outil **powershell**, utilise le à la place de **bash**

Bon, je ne l'ai mis en place qu'aujourd'hui, on va voir ce que ça donne à l'usage. En tout cas, je suis content de voir qu'Anthropic commence à prendre en compte les besoins des utilisateurs Windows.
