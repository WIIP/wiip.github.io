Un programme qu'on ne peut ni réinstaller ni désinstaller (erreur 2753 / 1603)

mercredi 25 novembre 2026
WindowsVaultInstallation

Vous voulez réinstaller un programme, et son installeur refuse : pour lui, le programme est déjà là. Vous essayez alors de le désinstaller, et la désinstallation échoue aussi. Le programme est coincé : inscrit dans Windows, mais impossible à réparer, à retirer ou à réinstaller.

Nous avons rencontré le cas avec le client Autodesk Vault 2027, lors d'une migration Vault sur un poste de développement. Mais rien dans ce qui suit n'est propre à Vault ni à Autodesk : la méthode vaut pour n'importe quel programme installé par Windows Installer (fichier .msi) et bloqué de la même façon.

Le symptôme

  • Le programme apparaît toujours dans Programmes et fonctionnalités (ou Applications installées sous Windows 11).
  • Son dossier d'installation, lui, a disparu — supprimé à la main, par un nettoyage, ou jamais complètement installé.
  • Son installeur refuse de l'installer de nouveau, puisqu'il le croit présent. Avec Vault 2027, le message parle même de configuration minimale, et renvoie au Panneau de configuration pour désinstaller d'abord la version présente :

  • La désinstallation échoue. Depuis une invite de commandes, msiexec /x {code produit} se termine par l'erreur 2753, avec le code de retour 1603 (échec fatal de l'installation).

La cause

Pour désinstaller un produit, Windows Installer a besoin de sa source d'installation : le .msi d'origine, ou la copie qu'il en garde en cache. Si cette source a disparu — dans notre cas, l'installeur avait été décompressé dans un dossier temporaire supprimé depuis —, il ne retrouve plus les fichiers nécessaires et abandonne.

L'inscription du programme reste alors dans le registre, orpheline : elle empêche la réinstallation, et rien ne permet plus de la retirer proprement.

La solution : l'outil de dépannage de Microsoft

Microsoft propose un outil dédié, le Program Install and Uninstall troubleshooter (« Résolution des problèmes d'installation et de désinstallation de programmes »). Selon Microsoft, il corrige notamment :

  • les clés de registre corrompues, y compris celles qui contrôlent les données de mise à jour ;
  • ce qui empêche d'installer un nouveau programme ;
  • ce qui empêche de désinstaller complètement ou de mettre à jour un programme existant ;
  • ce qui bloque la désinstallation depuis Programmes et fonctionnalités.

Il ne concerne que les programmes de bureau : pour une application du Microsoft Store, Microsoft renvoie vers une autre procédure.

Pas à pas

  1. Ouvrez la page de Microsoft : Fix problems that block programs from being installed or removed.
  2. Sélectionnez l'onglet « Windows 10 », même si votre poste est sous Windows 11. C'est sous cet onglet, et seulement là, que se trouve le bouton Download troubleshooter. L'outil n'est plus officiellement pris en charge, ce qui explique qu'il ne soit plus mis en avant ; il fonctionne pourtant toujours.
  3. Téléchargez l'outil, puis lancez-le (Exécuter ou Ouvrir).
  4. Choisissez Désinstallation : l'outil vous demande quel problème vous rencontrez.
  5. Sélectionnez le programme bloqué dans la liste. S'il n'y figure pas, l'outil vous demande son code produit (le GUID entre accolades, visible dans la table Property du .msi, ou sous la clé HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall).
  6. Confirmez la désinstallation, et soyez patient : l'outil est lent, et il peut tourner un bon moment sans donner signe de vie.
  7. Une fois l'inscription retirée, relancez l'installeur du programme.

Dans notre cas, l'outil a retiré l'inscription orpheline du client Vault 2027, puis l'installeur de Vault a installé le client normalement.

Précautions

  • Ne retirez que le programme fautif. Un produit en cache souvent plusieurs : avant de lancer l'outil, essayez une désinstallation normale de chacun. Chez nous, le module de langue de Vault s'est désinstallé sans difficulté, et le kit de développement (SDK) installé à côté n'avait aucune raison d'être supprimé : nous l'avons gardé. Ne supprimez pas tout à l'aveugle.
  • Gardez vos sources d'installation. Un installeur décompressé dans un dossier temporaire est la première cause de ce blocage : conservez le .msi ou le dossier d'installation tant que le programme est installé.
  • Évitez de nettoyer le registre à la main : l'outil de Microsoft fait ce travail sur les seules clés du produit choisi.

En résumé

Symptôme Cause Correction
Programme inscrit, mais son installeur refuse de l'installer Inscription orpheline dans le registre Retirer l'inscription avec l'outil de dépannage
msiexec /x échoue : erreur 2753, code 1603 Source d'installation (.msi) introuvable Outil de dépannage, onglet Windows 10 de la page Microsoft
