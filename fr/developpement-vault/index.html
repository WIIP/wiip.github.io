Développement Vault sur mesure

J'accompagne les bureaux d'études et les services informatiques dans le développement de compléments et intégrations Vault sur mesure. Mon objectif : fluidifier la gestion de vos données techniques, automatiser vos circuits de validation et connecter Vault à votre système d'information.

Autodesk Vault est un outil de gestion de données techniques (PDM/PLM) puissant, mais il prend toute sa valeur quand il est intégré dans votre écosystème : ERP, outils de production, processus métier...

Les technologies

C# / .NET (API Vault)

L'API .NET de Vault permet de développer des extensions côté client (intégrées dans l'explorateur Vault) et des applications autonomes. On peut manipuler les fichiers, les propriétés, les nomenclatures, les cycles de vie et les workflows.

Vault SDK / Job Processor

Le Job Processor de Vault permet d'exécuter des traitements automatiques en arrière-plan : export de PDF, mise à jour de propriétés, synchronisation avec un système externe... Je peux développer des jobs personnalisés qui s'intègrent dans le Job Processor existant.

API REST (Vault Data API)

Depuis Vault 2025, Autodesk propose une API REST moderne qui ouvre de nouvelles possibilités : intégration avec des applications Web, accès aux données depuis des plateformes non-Windows, automatisation via des scripts...

Extensions côté serveur

Vault permet de réagir à des événements serveur (changement de statut, enregistrement d'un fichier...) via des extensions IIS. C'est le mécanisme idéal pour déclencher des actions automatiques dans votre flux de travail : envoi de notifications, mise à jour d'un ERP, vérification de conformité...

Ce que je peux automatiser

Voici un aperçu de projets réalisés pour mes clients :

  • Connexion avec un ERP — Intégration bidirectionnelle avec des systèmes comme Clipper, Sylob, Sage X3 ou un ERP personnalisé : export de nomenclatures vers un fichier ou un service Web
  • Circuit de validation élaboré — Workflow personnalisé avec écriture du nom du validateur et de la date dans le cartouche du document
  • Restrictions sur les transitions — Règles métier imposant la saisie d'un commentaire ou la validation de certains champs avant un changement de statut
