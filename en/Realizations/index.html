Examples of achievements

AutoCAD

  • Horizontal and vertical formwork (choice of joist compositions, positioning of props and/or towers)
  • Installation of photovoltaic panels on a plot
  • Grating layout
  • Scaffolding installation
  • Sheet metal work
  • Truck crane configuration
  • Unfolding of flexible materials
  • Verification of graphic charter compliance
  • Converting drawings to as-built with PDF/A generation for archiving

Inventor

  • Drawing complex sketches
  • Connection with an ERP such as Clipper, Sage X3
  • Collection of dimensions and geometric tolerances present on a drawing for automatic generation of a control report
  • Generation of cut sheets (joinery profiles)

Revit

  • Extracting data from the model: net areas, baseboard lengths... Data can be written to a file (XML, Excel workbook) or sent to a Web service.
  • Batch sheet generation
  • Element numbering
  • Automated dimensioning of certain elements

Vault

  • Connection with an ERP such as Clipper, Sylob, Sage X3 (export bill of materials to file or Web service)
  • Elaborate validation workflow with writing of validator name and date in the title block
  • Restrictions on transitions to require comment entry

Standalone programs

  • DWG file compliance verification with graphic charter
  • Scaffolding configuration with material list and quote
  • Sheet metal profile editing with DXF import/export and STEP export

AutoCAD OEM

AutoCAD OEM allows you to create custom applications based on AutoCAD. I can assist you in creating your application.

Computer Aided Manufacturing (CAM)

Autodesk has a range of software for CAM:

  • PowerShape
  • PowerMill
  • PowerInspect

I can develop macros on these platforms to increase your productivity and/or improve your user experience.
