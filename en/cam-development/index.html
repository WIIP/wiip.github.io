Custom CAM Development

I help machine shops and toolmakers develop custom CAM macros and automation. My goal: automate your repetitive programming tasks, make your manufacturing processes more reliable, improve user comfort and reduce the risk of errors.

Autodesk offers a complete range of computer-aided manufacturing software. I can develop macros and automation on each of these platforms.

Software

PowerMill

PowerMill is the leading software for high-speed and multi-axis machining programming. Through its macro API, you can automate toolpath creation, stock management, machining strategy application and NC program export.

PowerShape

PowerShape is a hybrid modeling tool (surface, solid, mesh) designed to prepare models before machining. PowerShape macros allow automating part preparation: hole filling, fixture surface creation, draft analysis...

PowerInspect

PowerInspect is a metrology software for quality control on coordinate measuring machines (CMM). Macros allow automating measurement sequences and generating inspection reports.

Fusion 360

Fusion 360 combines 3D design, simulation and CAM in a cloud tool. Its Python and C++ API allows automating machining operations, generating parametric toolpaths and integrating CAM into a digital workflow.

Moldflow

Moldflow is a plastic injection simulation software. It allows optimizing mold design and injection parameters before manufacturing. Moldflow exposes a COM API, scriptable via Python, PowerShell or VBScript. Automation allows running series of parametric simulations, extracting results, customizing analysis reports, exporting results to external solvers (ABAQUS, ANSYS, NASTRAN, LS-DYNA…), computing geometric indicators (flatness, roundness) on warped parts, and managing material properties and fiber orientation across overmold analyses.

CNC Controllers

Beyond CAM software, I can also work on post-processing and interfacing with the main CNC controllers on the market:

  • Heidenhain (TNC, iTNC) — Custom post-processor development, specific machining cycles and conversational macros
  • Siemens (Sinumerik 840D, 828D) — Post-processors, ShopMill/ShopTurn cycles and automation
  • Fanuc — Post-processors, custom macros and fixed cycles adapted to your machines

The post-processor is the essential link between CAM software and the machine. A well-configured post-processor guarantees clean NC code, optimized for your machine and directly usable on the shop floor.

What I Can Automate

  • Automatic toolpath creation — Application of predefined machining strategies based on geometry type
  • Tool library management — Synchronization of tool libraries between software and machines
  • Model preparation — Automation of pre-machining operations (hole filling, surface extension, stock creation)
  • NC program export — Automatic generation and post-processing of programs for your machines
  • File transfer to and from machining centers — Automation of NC program transfer between the programming workstation and machines in both directions
  • Inspection reports — Automation of measurement sequences and report generation
