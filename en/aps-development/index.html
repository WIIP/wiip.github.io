Custom APS Development

I help companies develop Web and Cloud applications based on Autodesk Platform Services (APS, formerly Forge). My goal: allow you to leverage your CAD data beyond the workstation, by integrating them into your Web applications, client portals or business processes.

APS is a set of cloud APIs offered by Autodesk that open new possibilities: 3D visualization in the browser, automated server-side CAD file processing, construction data management...

Services

Viewer

The Autodesk Viewer allows you to display 3D models and 2D drawings directly in the browser, without client-side installation. It is optimized for large models and offers many features: 3D navigation, object selection with property display, sections, measurements, exploded views...

It is an ideal solution for spare parts catalogs, client portals or project review tools.

Automation API (Design Automation)

The Automation API allows running AutoCAD, Inventor, Revit or 3ds Max on cloud servers to process files automatically. You install a .NET add-in or script in APS, then send files to process with custom parameters.

Typical use cases: on-the-fly drawing customization, 3D model variant generation, format conversion, mass data extraction...

Model Derivative API

This API allows converting CAD files (DWG, RVT, IPT, IAM...) into web-ready formats (SVF/SVF2). It is the mandatory step for displaying a file in the viewer. It also allows extracting metadata and model hierarchy.

Data Management API

The Data Management API allows accessing files stored in Autodesk hubs (BIM 360, Autodesk Construction Cloud, Fusion Team). It handles versioning, permissions and project tree navigation.

Webhooks

APS webhooks allow reacting to events: file modification, status change, new version... This is the ideal mechanism for triggering automatic processing in your workflow.
