Preview DWG and DXF Files with QuickLook

Friday, March 13, 2026
CADAutoCADDWGDXF

When working with DWG or DXF files on a daily basis, opening AutoCAD just to check a file's contents is a waste of time. QuickLook solves this problem by bringing macOS's Quick Look feature to Windows: select a file, press Space, and a preview appears instantly.

Combined with the CADImport plugin, QuickLook can preview .dwg and .dxf files.

And of course, we can also preview PDF and Image files with QuickLook.

Installing QuickLook

QuickLook can be installed in two ways:

Via the Microsoft Store (recommended)

This is the simplest method. The application updates automatically and runs in a sandboxed environment.

Search for QuickLook in the Microsoft Store or click here.

Via the installer

Download the installer from the GitHub releases page. This method provides full functionality, including support for Open/Save dialogs.

Once installed, QuickLook launches automatically at Windows startup and sits in the notification area (taskbar).

Installing the CADImport plugin

  1. Go to the CADImport plugin releases page.
  2. Download the .qlplugin file.
  3. With QuickLook running, select the downloaded .qlplugin file and press Space.
  4. Click Install in the window that appears.
  5. Restart QuickLook.

Usage

The workflow is straightforward:

  1. Select a .dwg or .dxf file in Windows Explorer.
  2. Press the Space key.
  3. The drawing preview appears immediately.

Navigating the preview

  • Mouse wheel: zoom in / out
  • Double left-click: reset zoom
  • Right-click hold + drag: pan the view
  • Esc or Space: close the preview

Conclusion

QuickLook with the CADImport plugin is a simple yet highly effective tool for anyone who regularly works with AutoCAD files. No need to open CAD software just to quickly identify a file's contents — a single press of Space is all it takes.
