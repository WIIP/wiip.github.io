A program you can neither reinstall nor uninstall (error 2753 / 1603)

Wednesday, November 25, 2026
WindowsVaultInstallation

You want to reinstall a program, and its installer refuses: as far as it knows, the program is already there. So you try to uninstall it, and that fails too. The program is stuck: registered in Windows, but impossible to repair, remove or reinstall.

We ran into this with the Autodesk Vault 2027 client, during a Vault migration on a development workstation. But nothing below is specific to Vault or to Autodesk: the method works for any program installed by Windows Installer (an .msi file) and blocked the same way.

The symptom

  • The program still shows up in Programs and Features (or Installed apps on Windows 11).
  • Its installation folder is gone — deleted by hand, by a cleanup, or never fully installed.
  • Its installer refuses to install it again, since it believes it is present. With Vault 2027, the message even mentions minimum system requirements, and sends you to the Control Panel to uninstall the installed version first (screenshot of the French installer):

  • The uninstall fails. From a command prompt, msiexec /x {product code} ends with error 2753 and return code 1603 (fatal error during installation).

The cause

To uninstall a product, Windows Installer needs its installation source: the original .msi, or the copy it keeps in its cache. If that source is gone — in our case, the installer had been extracted to a temporary folder that was later deleted — it can no longer find the files it needs, and gives up.

The program's registration then stays in the registry, orphaned: it blocks the reinstall, and nothing can remove it cleanly anymore.

The fix: Microsoft's troubleshooter

Microsoft provides a dedicated tool, the Program Install and Uninstall troubleshooter. According to Microsoft, it fixes problems that:

  • corrupt registry keys, including those that control update data;
  • prevent new programs from being installed;
  • prevent existing programs from being completely uninstalled or updated;
  • block uninstalling a program through Programs and Features.

It only covers desktop programs: for a Microsoft Store app, Microsoft points to a different procedure.

Step by step

  1. Open Microsoft's page: Fix problems that block programs from being installed or removed.
  2. Select the "Windows 10" tab, even if your computer runs Windows 11. That tab, and only that tab, holds the Download troubleshooter button. The tool is no longer officially supported, which is why it is no longer promoted; it still works, though.
  3. Download the tool, then run it (Run or Open).
  4. Choose Uninstalling when the tool asks what problem you are having.
  5. Select the blocked program in the list. If it isn't listed, the tool asks for its product code (the GUID in braces, found in the MSI's Property table, or under the HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall key).
  6. Confirm the uninstall, and be patient: the tool is slow, and can run for quite a while without any sign of progress.
  7. Once the registration is removed, run the program's installer again.

In our case, the tool removed the orphaned Vault 2027 client registration, and the Vault installer then installed the client normally.

Precautions

  • Remove only the faulty program. A product often hides several: before running the tool, try a normal uninstall of each one. For us, the Vault language pack uninstalled without trouble, and the software development kit (SDK) installed alongside had no reason to go: we kept it. Don't remove everything blindly.
  • Keep your installation sources. An installer extracted to a temporary folder is the first cause of this deadlock: keep the .msi or the installation folder as long as the program is installed.
  • Avoid cleaning the registry by hand: Microsoft's tool does that job on the selected product's keys only.
