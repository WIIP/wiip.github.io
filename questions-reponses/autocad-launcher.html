C'est quoi AutoCAD Launcher ?

Dernière mise à jour : lundi 18 août 2025
AutoCADCAO

Lorsque vous double-cliquez sur un fichier DWG dans l'explorateur Windows, c'est un petit programme nommé AutoCAD Lancher qui s'exécute.

Ce programme est installé dans C:\Program Files\Common Files\Autodesk Shared\AcShellEx. L'exécutable principal est AcLauncher.exe.

Ce petit utilitaire sert à lancer le dernier programme AutoCAD utilisé (si plusieurs programmes AutoCAD sont installés sur votre ordinateur).

C'est quoi un "programme AutoCAD" ? En fait, vous pouvez avoir plusieurs versions d'AutoCAD installées sur votre ordinateur (AutoCAD 2025, AutoCAD 2026, etc.) ou plusieurs variantes (AutoCAD, AutoCAD Mechanical, AutoCAD Electrical, etc.). Vous pouvez également installer AutoCAD dans différentes langues (français, anglais, italien, etc.).

Si vous préférez toujours ouvrir vos DWG dans une version spécifique, vous pouvez choisir Ouvrir avec dans le menu contextuel de l'explorateur Windows. Là, vous allez trouver certainement plusieurs entrées AutoCAD mais il est difficile de déterminer la version exacte qui se cache derrière chaque entrée. Le seul indice, c'est l'icône, mais vous ne les connaissez sûrement pas par cœur et comme elle n'a pas changé pour certaines versions, ça n'aide pas beaucoup.

Le mieux c'est de sélectionner Choisir une autre application, tout en bas de la liste. Là, vous pouvez aller chercher l'exécutable correspondant à la version d'AutoCAD que vous voulez utiliser. Par exemple, pour AutoCAD 2026, l'exécutable se trouve dans C:\Program Files\Autodesk\AutoCAD 2026\acad.exe.
