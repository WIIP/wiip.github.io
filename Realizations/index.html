Exemples de réalisations

AutoCAD

  • Coffrage horizontal et vertical (choix des compositions de poutrelles, positionnement des étais et/ou des tours)
  • Implantation de panneaux photovoltaïques sur une parcelle
  • Calepinage de caillebotis
  • Implantation d'échafaudages
  • Tôlerie
  • Configuration de camion-grues
  • Dépliage de matériaux souples

Inventor

  • Tracé d'esquisses complexes
  • Connection avec un ERP type Clipper, Sage X3
  • Collecte des cotes et tolérances géométriques présents sur un dessin pour génération automatique d'un procès-verbal de contrôle

Revit

  • Extraction de données de la maquette : surfaces nettes, longueurs de plinthes... Les données peuvent être écrites dans un fichier (XML, classeur Excel) ou envoyé à un service Web.
  • Génération de feuilles en lot
  • Numérotation d'éléments
  • Cotation automatisée de certains éléments

Vault

  • Connection avec un ERP type Clipper, Sylob, Sage X3 (export nomenclature vers fichier ou service Web)
  • Circuit de validation élaboré avec écriture du nom du validateur et de la date dans le cartouche
  • Restrictions sur les transitions pour imposer la saisie d'un commentaire

Programmes autonomes

  • Vérification conformité fichiers DWG avec charte graphique
  • Configuration d'échafaudages avec liste de matériel et devis
  • Edition de profil de tôlerie avec import/export DXF et export STEP

AutoCAD OEM

AutoCAD OEM permet de créer des applications personnalisées basées sur AutoCAD. Je peux vous assister dans la création de votre application.

Conception et Fabrication Assistée par Ordinateur (CFAO)

Autodesk dispose d'une gamme de logiciels pour la CFAO :

  • PowerShape
  • PowerMill
  • PowerInspect

Je peux vous développer des macros sur ces plateformes pour augmenter votre productivité et/ou améliorer votre confort d'utilisation.
